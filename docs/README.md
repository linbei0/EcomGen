# EcomGen 文档

EcomGen 是面向个人卖家的本地 Web 套图工作台。一个项目对应一个商品款（SPU），可管理多个 SKU 变体；用户选择目标平台与图片类型后上传素材，由 Pi Agent 规划并生成可审核的电商套图。

当前阶段先开发后端。前端 Agent 必须以 [OpenAPI 契约](openapi.yaml) 和 [接口说明](06-API接口契约.md) 对接，不自行猜测字段或端点。

## 已确认边界

- 首版桌面优先，开发于 Windows；直接使用者通过 Docker Compose 部署。
- 同一仓库的 `web`、`api`、`worker` 三个独立应用，不使用 Next.js 一体化架构。
- 平台 UI 只显示“国内平台”和“Amazon”；国内在内部使用共用视觉策略和可版本化覆写。
- 一个项目对应一个 SPU；每个分镜绑定“通用”或一个明确 SKU 变体。
- 用户先选平台与图片类型，再上传素材；Agent 的推荐计划必须由用户确认后才创建生图任务。
- 支持创意模式和主体像素保护模式；项目设置默认模式，分镜可覆盖。
- 用户自行选择推理模型与生图模型。Pi 接入多个 Provider；没有视觉能力的推理模型允许继续，但不自动识图。
- 素材不完整不拒绝。不得编造价格、参数、认证、功效、赠品等可核验事实。
- 默认每个分镜仅生成 1 张；变体数量必须由用户明确选择。
- 首版只做轻量重试，不做自由画布、复杂局部编辑、自动发布平台、多租户或支付。
